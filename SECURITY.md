# Security Policy

| Version | Supported          |
| :---    | :---               |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Security is a primary concern for **ModsTams**. If you discover a security vulnerability or security flaw, please adhere to responsible disclosure:

1. **Do not create public GitHub issues** for security vulnerabilities.
2. Send a detailed description of the vulnerability, reproduction steps, and potential impact privately to the maintainers.
3. We will acknowledge receipt of your vulnerability report within 48 hours and provide a timeline for patch deployment.
4. Once verified and resolved, a security advisory and patch release will be published.
